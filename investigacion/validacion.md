# ¿Acierta el ranking?

_Comprobación automática del buscador de oportunidades. Se actualiza cada día._

**Todavía no hay historia suficiente.** El sistema guarda una foto del ranking cada día (fotos guardadas: 1). En una semana saldrá la primera comparación, y a partir de 3-6 meses empezará a significar algo.
